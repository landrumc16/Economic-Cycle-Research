## Safeguards preserved (unchanged code paths)
- **Withhold the judgment** when the gate is stale, or when an observation is missing, unverified or future-dated. Unpublished months are never imputed. No historical signal uses later data.
- **Monthly publication:** only `PASS` assessments publish. The V6.2 manifest is stamped only on `PASS`. The daily publisher keeps the last accepted monthly report and V6 bundle when no replacement qualifies, and refuses deployment if the previous report can't be verified.
- **Scorecard:** the page refuses any card claiming predictive skill or probabilities.
- **Daily job:** runs only on `main` (protected `github-pages` environment).

## Deployment procedure (after explicit owner authorization)
1. **Pre-merge check:**
   - `git ls-remote origin claude/economic-cycle-v6-3-pk78e3` equals the release commit above;
   - the branch is still 0 behind `main`;
   - avoid merging within about 30 minutes of the 12:15 UTC daily schedule.
2. **Merge:** open a PR `claude/economic-cycle-v6-3-pk78e3` → `main` and merge with the head SHA pinned. Record the merge commit.
3. **Workflows on the merge commit** (expected order):
   - V6.2 Release Contracts ✓;
   - Monthly Economic Cycle Assessment ✓ (rebuilds V6.3 pages and stamps the manifest; the replay step must pass);
   - Milestone 1 `workflow_run` ✓, including "Publish qualified V6 bundle", "Deploy approved dashboard to GitHub Pages" and "Verify deployed public dashboard and research pages". The concurrent push-triggered Milestone 1 run is normally cancelled by design.
4. **Live verification:**
   - `v62_release_manifest.json` `build_commit` equals the merge commit, with `NEW_QUALIFIED` and the current assessment date;
   - the homepage shows the V6.3 condition, direction, evidence confidence, drivers, counterevidence, evidence gaps and reversal conditions;
   - `historical.html` shows the scorecard ("flagged before the peak" wording, outcome tests, base rates);
   - `research.html#rubric` is present;
   - all 11 `sector-NN.html` pages show "Economic backdrop now";
   - `monthly.json` is current and not stale.
5. **Record** the merge commit, run IDs, Pages deployment IDs and live check results here, then start the owner evaluation (`V6.3_OWNER_EVALUATION_CHECKLIST.md`).

## Rollback procedure
- **Trigger:** any failed step 3 or 4 check, or an owner request.
- **Action:** revert the V6.3 merge commit on `main` (back to `a690a00` content) and re-run Milestone 1 (workflow_dispatch on `main`). The monthly workflow can be re-run first if a fresh V6.2 artifact is needed.
- **Verify:** the live manifest `build_commit` equals the revert commit, the V6.2 homepage is back, and 11 sector pages are present.
- If the monthly artifact doesn't qualify, the publisher keeps the last accepted publication, which is safe by design.
- Retention of older Pages artifacts was not verified, so revert plus re-run is the supported path.

## Known limitations (disclosed; accepted for this release)
- Revised (current-vintage) data, not real-time vintages. Few recessions in the replay sample.
- The deterioration signal mostly confirms recessions after they begin. Firming adds little information beyond the base rate.
- October 2025 CPI and unemployment were never published:
  - V6.3 uses the previous month, dated and noted;
  - the prior-year unemployment comparison is unavailable until January 2027 data.
- Sector sensitivities are not validated against sector returns. No qualified valuation or earnings sources yet.
- Human accessibility evaluation is outstanding.

## Operational note
- A branch dispatch of the monthly workflow starts a `main` Milestone 1 run that fails harmlessly before publishing.
- These runs share the production concurrency group, so avoid branch dispatches near 12:15 UTC.
