## Rubric thresholds (published)
Growth flat band ±0.5%; growth momentum ±0.5 pt over 3 months; unemployment +0.3 pt over 3 months = deteriorating, −0.2 pt = improving; 3-month average unemployment +0.5 pt above prior-year low = deteriorating (Sahm-style, known false alarms); CPI ≤2.5% near goal, >4% high; inflation trend ±0.3 pt over 3 months; observations must be ≤2 months old.

## Release blocker found (pre-existing, affects production)
`v5_integrated_acceptance.py` requires `v5_unified_portal.observation_month` (latest month common to the five V5 timeline series) to equal the monthly gate's `common_observation_month` (latest month common to all eight series, including slower housing and income data). With data newer than the last green `main` run (2026-11-05), these months differ. V6.3 does not touch this code, so the scheduled `main` run on 2026-11-20 is expected to fail the same way. The daily workflow would then keep the last accepted monthly publication, as its safeguards intend. The fix needs an owner/methodology decision: either align both modules on one observation-month definition, or compare each against its own source. It also blocks the real-data V6.3 replay and M5.
