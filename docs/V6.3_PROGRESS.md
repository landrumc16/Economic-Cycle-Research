## Scorecard outcome definitions (clarified 2026-11-17; scores unchanged)
- **Cautious calls** (Weakening, Softening) count as right if unemployment rose ≥ 0.2 pt **or** production growth fell ≥ 1 pt within 6 months. Base rate: 54%.
- **Constructive calls** (Steady, Firming, Strengthening) count as right if unemployment did not rise ≥ 0.2 pt. Base rate: 65%.
- The tests overlap and are not complements. Each share is compared only with its own base rate; lift below 5 pt is labelled "not informative". This is stated on the Historical page, in the scorecard JSON and markdown, and in the review pack.
